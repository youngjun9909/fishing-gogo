# 옷 메시를 기본 몸에 붙이는 조건

마스터 시트(`docs/character/master-sheet.md`, 2026-11-06)를 따른다. 기준 몸은 `base_model/female/female_base.glb`, `male/male_base.glb`(남녀 마네킹)이다.
- 뼈대: Mixamo 이름 65개(`mixamorig:` 접두어), 가중치 빈 점 0개(확인됨).
- 재질 1개, 얼굴은 텍스처에 구워짐. 몸 약 3만 삼각형, 텍스처 4096(확인됨).
- 남녀 뼈 축 기울기가 약 7도 달라 가중치는 남녀 각각 몸 기준으로 옮겨야 한다(시트 4절).

## 확인한 현재 상태
- (옛 방식, 지금은 쓰지 않음) 예전에는 `character.glb`(몸)와 `hairs.glb`(머리카락)를 썼다. 지금은 `body_outfits.glb`(여자), `body_male.glb`(남자), 머리카락 8종 GLB를 쓰고, 옷은 몸 모델 안의 옷 메시를 보이게 하는 방식이다(`client/src/three/character.ts`).
- 옷을 별도 메시로 붙이는 코드는 아직 없다(코드는 건드리지 않음).

## 1. 기본 조건

| 항목 | 조건 | 이유 |
|---|---|---|
| 뼈대 | 옷은 **기본 몸과 같은 뼈 이름·구조**의 뼈대(Armature)를 쓴다 | 몸을 움직일 때 옷도 같이 움직이게 |
| 자세 | 기본 몸과 같은 T자 | 가중치 전달이 쉽다 |
| 원점/크기 | 몸과 같은 원점, 같은 단위, 같은 스케일 | 크기 어긋남 방지 |
| 좌우 | 신발 한 짝은 미러 사용 | 폴리곤·텍스처 절약 |
| 법선 | 미러 후 법선이 바깥으로 향하는지 확인 | 뒤집힌 면 방지 |
| 재질 이름 | `Top`, `Bottom`, `Shoe`, `Sole` 등 고정 이름(제안) | 코드에서 색 입히기 |
| 파일 | GLB, 부품별 1파일(`top_default.glb` 등, 이름 제안) | 교체 쉬움 |

## 2. 몸과 겹치는 부분 숨기기

옷을 입으면 그 아래 몸 부분은 보이지 않아야 한다(옷 뚫림 방지).
- 방법 A(권장): 기본 몸 메시를 **부위별 면 그룹**(몸통, 팔, 다리, 발)으로 나눠 두고, 옷을 입으면 해당 그룹을 숨긴다.
  - 상의 → 몸통·팔 숨김(목, 손, 손목 끝은 남김)
  - 하의 → 다리 윗부분 숨김
  - 신발 → 발 숨김
- 방법 B: 옷 안쪽에 몸을 **축소(약간 작게)**해서 뚫림 방지(숨김보다 부정확).
- 몸을 만드는 쪽(사용자 새 기본 몸)에게 **부위별 분리** 요청이 필요하다(해야 할 일).
- 확인: 새 몸은 재질이 1개라 재질로는 부위를 숨길 수 없다. 부위별 면 그룹 분리 여부는 미확인 → 몸에서 옷 아래 면을 지우거나 분리하는 작업이 필요하다(Blender, 이 문서 범위 밖).

## 3. 가중치(스키닝)

- 옷의 각 점은 몸 뼈 1~4개에만 가중치를 받는다(웹 3D 한계).
- 상의: 몸통은 척추 뼈, 소매는 어깨-팔 뼈에 큰 가중치. 소매통은 팔 뼈를 따라 회전.
- 하의: 허리 윗부분은 골반·척추, 다리통은 허벅지·정강이 뼈. **바지통이 넓을 때 두 다리통 사이가 뭉개지지 않게** 가랑이 쪽 가중치를 신중히.
- 한복 치마: 허리~무릎은 골반, 치마 아래쪽은 다리 뼈로 점점 풀어 준다. 긴 치마가 걸을 때 다리 사이로 찢어지지 않게.
- 가중치 이전: 새 기본 몸의 가중치를 옷에 **가까운 표면 기준으로 복사**한 뒤 손으로 다듬는 방식이 가장 현실적(Blender, 이 문서 범위 밖).
- 뼈: Mixamo 65개. 상의는 Spine/Spine1/Spine2, Shoulder, Arm, ForeArm, Hand; 하의는 Hips, UpLeg, Leg; 신발은 Foot, ToeBase를 쓴다(뼈 이름 일부는 시트 4절 확인, Spine1 위치 등은 미확인).

## 4. 폴리곤 수 목표 (제안값, 확정 아님)

마스터 시트 8절: 캐릭터 한 명 합계 약 5만 이하, 몸이 약 3만이므로 머리카락+옷 합계 약 2만 이하(몸 감량 작업이 따로 있으면 여유가 늘어난다). 아래 값은 이에 맞춘 제안값이다.

| 부품 | 목표(삼각형) | 상한 |
|---|---|---|
| 상의 | 3,000 ~ 5,000 | 8,000 |
| 하의 | 2,500 ~ 4,000 | 6,000 |
| 신발(한 짝) | 1,000 ~ 2,000 | 3,000 |
| 옷 한 벌(세트) | 8,000 이하 | 12,000 (머리카락과 합쳐 2만 이하) |

근거: 한 화면에 여러 플레이어가 동시에 보이므로(멀티 게임, 확인함) 캐릭터당 총량을 낮게 유지해야 한다. 정확한 동시 접속 수와 성능 한계는 **미확인**(테스트 필요).

Tripo 결과는 폴리곤이 보통 많다. 후처리(감소)가 필요할 수 있다(Blender 세션, 이 문서 범위 밖).

## 5. 텍스처

- 마스터 시트 8절: 부품별 1024~2048 이하. 옷 부품 한 장씩, 1024 권장(제안).
- 색 변경은 시트 8절대로 흰색~회색 텍스처에 게임에서 색을 곱한다.
- 회색조 마스크 방식([outfit-types.md](outfit-types.md) 5번)을 쓰면 마스크는 같은 UV를 공유해야 한다.

## 6. 두께와 겹침 관리

- 옷 메시는 몸 표면에서 **일정 거리 바깥**(옷 두께만큼) 떠 있어야 한다. 마스터 시트 7절: 옷은 몸보다 약 1~2cm(0.01~0.02, 키 1.000 기준) 크게. 신발 밑창 두께는 미확인(디자인으로 정함).
- 옷끼리 겹침: 스웨터 밑단이 바지 허리 위로 덮이도록 상의가 하의보다 바깥에 있어야 한다.
- 소매 끝단은 손 위에서 멈춰야 한다(손은 항상 보인다).

## 7. 검증 방법 (옷 GLB를 받았을 때)

1. 기본 몸에 입혀서 정면·측면·뒤에서 뚫림 확인.
2. 걷기/낚시 애니메이션에서 팔·다리를 크게 움직였을 때 찢어짐·뚫림 확인.
3. 폴리곤, 텍스처 크기 확인.
4. 기본 옷 + 3종(우비, 한복, 멜빵바지) 각각 입혀 비교.
5. 다른 체형(게임에 3종 체형이 있음, 확인함: `BODY_SCALE[a.body % 3]`)에서 뚫림 확인.

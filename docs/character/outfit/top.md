# 상의 제작 가이드

기본 상의 = 노란 스웨터. 구조는 [base-outfit.md](base-outfit.md) 1번 참고.
결과물: 몸 없이 **옷만** 있는 3D 메시 1개(GLB).

## 1. 구도 규칙 (이미지 AI)

- 몸·머리·손·얼굴이 **없는** 옷만. 마네킹도 넣지 않는다(마네킹이 같이 3D로 변환됨).
- 옷이 속이 빈 상태로 서 있는 모양(투명 마네킹에 입힌 듯 안이 보이는 "고스트 마네킹")이 이상적. 목 구멍, 소매 입구, 밑단 입구가 열려 있고 안쪽 천이 살짝 보인다.
- **T자로 소매를 옆으로 펼친 모양**. 목표 이미지의 팔 자세와 같다.
- 단색 배경: 연한 회색 또는 흰색 한 가지, 그림자·바닥선·그라데이션 없음.
- 뷰 3장을 같은 크기·같은 높이로: **정면, 측면(옆), 뒤**. 카메라 정면 정사영(원근 왜곡 최소), 옷이 화면 중앙, 여백 넉넉히.
- 조명은 부드럽고 균일하게. 진한 그림자·반사·하이라이트 없음(그림자는 3D로 변환될 때 색으로 굳는다).

## 2. 프롬프트

### 한국어
> 옷만 있는 제품 사진. 몸과 마네킹 없이 속이 빈 상태로 떠 있는 노란 스웨터. 둥근 크루넥 목선에 얇은 리브 테두리. 헐렁하고 두툼한 상자형 몸통, 어깨가 처진 넉넉한 핏. 소매는 통이 넓고 길며 옆으로 곧게 펼친 T자 모양, 소매에 부드러운 가로 주름. 소매 끝에 두툼한 도톰한 밴드(커프). 밑단에 얇은 리브 밴드. 부드러운 니트 질감이지만 표면은 매끈하게 단순화. 연한 버터 노랑, 무늬·로고·글자 없음. 귀여운 치비 3D 게임 캐릭터 의상 스타일, 균일한 부드러운 조명, 그림자 없음, 단색 연한 회색 배경, 정면.

### English
> Product shot of clothing only, no body and no mannequin: a pale butter-yellow knit sweater floating hollow, with open neck, sleeve and hem openings. Round crew neck with a thin ribbed collar. Oversized, thick, boxy body with dropped shoulders. Wide long sleeves held straight out in a T-pose, soft horizontal wrinkles on the sleeves, thick chunky cuffs at the sleeve ends, thin ribbed hem band. Smooth simplified knit surface, no pattern, no logo, no text. Cute chibi 3D game character costume style, even soft lighting, no cast shadow, plain light gray background, front view.

측면·뒤 뷰는 같은 프롬프트 끝의 "front view"를 "side view" / "back view"로 바꾸고, **같은 그림에서 이어서 만들도록** 이미지 AI의 참조/편집 기능을 쓴다(처음부터 새로 뽑으면 무늬가 달라진다).

## 3. "몸에 칠한 것"처럼 보이지 않게 하는 요령

1. 프롬프트에 항상 `oversized, thick, hollow, open neck/sleeve/hem openings`(헐렁, 두꺼움, 속 빔, 입구 열림)를 넣는다.
2. 소매 끝과 밑단, 목 둘레에 **입구 두께**(천의 단면)가 보이는 그림을 고른다. 단면이 보여야 3D에서도 두께가 생긴다.
3. 옷 윤곽이 몸보다 **한 단계 크게** 나온 그림을 고른다(몸에 붙은 얇은 그림은 불합격).
4. 큰 주름 3~5개만 있고, 잔주름은 없는 그림을 고른다(잔주름은 3D에서 찌그러진다).
5. 그림이 맘에 들면 Tripo 입력 전, 필요하면 그림 편집으로 안쪽 구멍(목, 소매, 밑단)이 어둡게 보이도록 다듬는다.

## 4. Tripo 입력 조건

- 입력: 위 정면 1장, 또는 정면+측면+뒤(Tripo가 다중 뷰를 받는지는 **미확인** — Tripo 화면에서 확인).
- 배경이 단색이어야 한다. 가능하면 배경 제거 후 투명 PNG.
- 해상도: 정사각, 옷이 화면의 70~80%. (정확한 최소 해상도는 미확인)
- 결과 모델에서 확인할 것: 안이 비어 있는지(속이 막힌 덩어리 아님), 소매 입구가 뚫려 있는지, 한 덩어리 메시인지, 색이 텍스처로 구워졌는지.
- 속이 막힌 덩어리로 나오면: 그림의 입구를 더 크게 그리게 하거나 다시 생성. 해결 안 되면 후처리 대상(Blender 담당, 이 문서 범위 밖).
- 상업 사용: 유료 플랜 필요(사용자 확인 사항). 무료 플랜으로 만든 결과는 쓰지 않는다.

## 5. 합격 체크리스트 (그림 단계)

- [ ] 몸/손/얼굴/마네킹 없음
- [ ] 목·소매·밑단 입구가 열려 있음
- [ ] T자 소매
- [ ] 단색 배경, 그림자 없음
- [ ] 크루넥, 두툼한 소매 끝단, 밑단 밴드가 보임
- [ ] 로고·글자·무늬 없음
- [ ] 정면/측면/뒤 모양이 일치

## 6. 하지 말 것

- 사람이 입은 사진 쓰지 않기(몸이 옷에 구워짐).
- 몸에 딱 붙는 얇은 옷 금지(별도 메시 느낌이 사라짐).
- 로고, 글자, 줄무늬, 복잡한 니트 무늬 금지(색 변경 시 깨짐, 폴리곤 증가).
- 강한 그림자·반사·빛 번짐 금지.
- 후드·지퍼·단추·끈 같은 작은 부품 금지(기본 상의에는 없다).
- 소매를 내린 자세 금지(T자가 기본 몸 포즈와 맞는다).
- 일본어 문구를 프롬프트나 결과물에 섞지 않는다.

## 7. 치수 (마스터 시트 3·4·7절 기준, 키 = 1.000, 게임에서 약 2.6배 확대)

| 항목 | 값 | 출처 |
|---|---|---|
| 어깨선 높이 | z 0.52~0.56 | 7절 |
| 몸통 반폭 | 0.085~0.10 (앞 깊이 0.085~0.095, 뒤 0.03~0.06) | 3절 |
| 옷 두께 | 몸보다 약 1~2cm (0.01~0.02) | 7절 |
| 소매 높이 | 팔 z 0.51~0.58 | 7절 |
| 손목 위치 | 약 x 0.27 (LeftHand 뼈 x 0.271~0.272). 소매 끝단은 여기서 멈춘다 | 7절, 4절 |
| 팔 시작 | 몸 가운데에서 약 0.2 바깥부터 | 3절 |
| 팔 벌린 폭 | 0.72 (반폭 0.36) | 3절 |
| 목 | z 약 0.58~0.62 (목 뼈 0.588~0.591) → 크루넥 목 구멍 위치 | 3·4절 |
| 밑단 | 하의 허리(z 약 0.36~0.40)를 덮는 높이 | 7절 |

- 미확인: 목 둘레 지름, 소매통 지름, 팔 굵기(마스터 시트에 값 없음).
- 어림(확정 아님): 몸통 반폭 0.085~0.10에 1~2cm를 더하면 상의 반폭 약 0.10~0.12.
- 남녀 몸 형태가 거의 같으므로 상의는 남녀 공용으로 만든다(마스터 시트 1절).

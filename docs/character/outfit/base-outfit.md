# 기본 옷 구조 (노란 스웨터 · 회색 바지 · 노란 운동화)

출처: 목표 이미지(정면+측면 시트), `ref/hair_iter/final_front.png`, `final_q3.png`.
목표 이미지는 T자 자세, 회색 단색 배경이다. 아래는 눈으로 본 것만 적었다. 정확한 치수는 마스터 시트가 생기면 채운다.

## 1. 상의: 노란 스웨터

| 부분 | 목표 이미지에서 보이는 것 |
|---|---|
| 색 | 연한 버터 노랑(따뜻한 노랑, 형광 아님). 전체가 거의 한 색, 주름 그늘만 살짝 진함 |
| 목선 | 둥근 크루넥. 목 둘레에 얇은 고리 모양 테두리(리브)가 한 줄 보인다. 브이넥·터틀넥 아님 |
| 몸통 | 헐렁한 상자형. 어깨선이 처져 있고 가슴-허리 폭이 거의 같다. 몸에 붙지 않는다 |
| 소매 | 통이 넓고 길다. T자 자세에서 옆으로 곧게 뻗고 손목 쪽으로 약간 좁아진다. 소매에 큰 주름이 몇 줄 가로로 생긴다 |
| 소매 끝단 | 두툼한 밴드(커프). 소매 본체보다 살짝 어두운 노랑이고 고리처럼 도톰하다. 손은 이 밴드 밖으로 나온다 |
| 밑단 | 허리 아래까지 내려와 바지 윗부분(허리~엉덩이)을 덮는다. 아래쪽에 얇은 밴드(리브)가 있고 가장자리가 살짝 물결친다 |
| 질감 | 매끈한 니트. 무늬·로고·글자 없음 |

실루엣 요점: 어깨~소매는 몸보다 **훨씬 크고 두껍다**. 치비 몸통 위에 천 한 겹이 떠 있는 느낌이 핵심이다.

참고: 게임에 들어간 `final_front.png`(현재 3D)에서는 소매와 밑단이 단순화되어 있고 목선 리브가 거의 안 보인다. 목표 이미지가 기준이다.

## 2. 하의: 회색 와이드 바지

| 부분 | 보이는 것 |
|---|---|
| 색 | 중간 회색(약간 따뜻한 회색), 무광 천 |
| 허리 | 스웨터 밑단에 가려 허리띠·고무줄은 안 보인다. 스웨터 밑단 바로 아래에서 시작 |
| 통 | 허벅지부터 밑단까지 넓고 곧게 떨어지는 와이드 핏. 다리에 붙지 않는다. 다리 두 개가 각각 큰 통 하나처럼 보인다 |
| 주름 | 무릎 위아래로 세로로 길게 떨어지는 주름. 밑단 쪽에 천이 쌓인 가로 주름 약간 |
| 앞 중심 | 가운데 가랑이 선(앞 솔기)이 위에서 아래로 짧게 보인다 |
| 주머니 | 앞쪽 허리 옆에 비스듬한 주머니 입구 선이 양쪽에 하나씩 |
| 밑단 | 접어 올린 단(밑단 접힘)이 있어 가장자리가 약간 두껍고 주름진다. 신발 윗부분을 반쯤 덮는다 |

미확인: 뒷주머니 유무(목표 이미지는 정면만 있음). 측면에서 바지 옆선(솔기)이 보이는지.

## 3. 신발: 노란 운동화

| 부분 | 보이는 것 |
|---|---|
| 색 | 상의와 비슷한 밝은 노랑. 밑창은 흰색 |
| 앞코 | 둥글고 통통하다. 앞코 끝이 위로 약간 부풀어 있다 |
| 밑창 | 흰색 고무 밑창. 두께가 있고 가장자리가 둥글다 |
| 끈 | 신발 위 가운데에 흰 끈이 지그재그로 한 묶음 보인다(리본 매듭은 작게) |
| 발목 | 낮은 신발(로우탑). 바지 밑단이 발목 위를 덮는다 |

## 4. 천 겹 순서 (바깥 → 안)

스웨터 밑단 → 바지(허리 부분은 스웨터 아래에 숨음) → 바지 밑단 → 신발 윗부분 → 몸(발목, 손목, 목).
몸이 옷 밖으로 보여야 하는 곳은 **목, 손, 손목 끝, 발목 일부**뿐이다.

## 5. 현재 게임 코드와의 관계 (확인한 사실)

- `client/src/three/character.ts`는 `character.glb`의 재질 이름 `Sweater`, `Pants`, `Shoe`, `Sole`에 색을 칠한다. 즉 지금 옷은 **몸 메시에 색만 다른 재질**로 붙은 것이다.
- 이 문서의 목표는 옷을 **몸에서 분리된 별도 메시**로 만드는 것이다. 코드 변경은 이 세션 범위 밖이다.
- 새 기본 몸(마스터 시트)은 남녀 마네킹이고 재질이 1개, 얼굴이 텍스처에 구워져 있다. 위의 `Sweater/Pants/Shoe/Sole` 재질 이름은 새 몸에 없을 것으로 본다(미확인: 새 몸을 게임에 아직 붙이지 않음).

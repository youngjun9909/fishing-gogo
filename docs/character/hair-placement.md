# 머리카락 4종 배치 기록 (여자 마네킹 기준)

> 사용자가 Blender에서 세밀하게 고친 값이 있으면 아래 표를 사용자 값으로 갱신한다.
> 파일: `base_model/hair_fit.blend` (2026-11-06 저장). 원본 Tripo: `base_model/male/hair4-1.glb` (4개가 한 장).
> 마네킹: `base_model/female/female_base.glb` (Blender에서 x = -1.0 위치에 놓음, 머리 중심 x -0.999).

## 공통 (2026-11-06 사용자 수정 반영)
- 파일에는 마네킹 4개(`Mannequin_1_ponytail` ~ `Mannequin_4_long`)가 x = -1.0, -2.3, -3.6, -4.9에 있고, 머리카락은 각 마네킹의 자식이다.
- 아래 위치는 **마네킹 기준 상대 위치**(마네킹 원점에서의 거리)다. 형태는 건드리지 않았고 회전은 모두 0이다.
- 원본은 Tripo 한 메시(`base_model/male/hair4-1.glb`)를 2×2 칸으로 나눈 것.

## 알려진 문제
- 단발과 긴 생머리 정수리에 어두운 네모 자국(텍스처에 그려진 빈 곳). 위에서 볼 때만 보인다.
- 남자 마네킹(`male_base.glb`)에 같은 값이 맞는지는 미확인. 남녀 머리 폭 차이는 0.01 이하.
- 뼈대(`mixamorig:Head`)에는 아직 연결하지 않았다.

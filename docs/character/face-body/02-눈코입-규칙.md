# 얼굴 규칙: 체형 모델 1개 = 고정 얼굴

## 1. 새 구조 (확정된 것)
- 눈, 코, 입, 볼 홍조는 **모델 안에 고정**된 값이다. 사용자가 눈/코/입을 따로 고르지 않는다.
- 사용자가 고르는 것은 **몸 형태(체형 모델)**. 체형 모델을 바꾸면 그 모델에 들어 있는 고정 얼굴이 함께 바뀐다.
- 게임 코드의 `face.ts` 데칼 방식(눈 10·코 6·입 8종)은 **폐기 대상**이다. (코드는 이 문서 작업에서 고치지 않음. 실제 삭제 시점은 미확인)
- 얼굴은 Tripo 등으로 만들 때 **머리 모델에 포함되어 나온다**. 눈, 입을 별도 부품으로 분리하지 않는다.

## 2. 체형 모델 하나가 가져야 할 얼굴 규칙
목표 이미지 기준(`01-얼굴-분석.md`):
- 눈: 매우 크고 둥긂, 홍채가 눈의 85~90%, 큰 흰 하이라이트 1개(위, 코 쪽), 굵은 윗 속눈썹(바깥 꼬리 살짝), 아랫선 거의 없음. 좌우 대칭.
- 눈 위치: 머리 높이를 위에서 아래로 약 74%, 두 눈 중심 간격은 머리 높이의 약 36%(대략값).
- 눈썹: 가늘고 짧고 연한 갈색(눈썹 형태가 모델에 포함되는지는 미확인).
- 코: 거의 없음(아주 작은 그림자 정도). 입체 코를 만들지 않는다.
- 입: 매우 작고 얇은 가로선, 약한 미소. 눈 한 개 폭의 절반 이하.
- 볼 홍조: 눈 바깥 아래의 연한 분홍 타원 두 개(색으로 모델 텍스처에 포함).
- 모델마다 얼굴 비율이 달라도 되지만, 한 모델 안에서는 고정이다.

## 3. 표정 변화 없음 (사용자 확정)
- 표정은 **바뀌지 않는다**. 걷기, 낚시 등 어떤 동작에서도 얼굴은 모델에 들어 있는 그대로다.
- 따라서 표정 세트와 구현 방식 비교(변형 키 / 텍스처 교체 / 얼굴 메시 교체)는 **해당 없음**이다.
- 눈 깜빡임 같은 미세 움직임도 이번 범위에서 **제외**한다. 필요해지면 나중에 별도로 결정한다.

## 4. 체형 모델 후보를 Tripo용으로 만들 때 얼굴 규칙
(몸 이미지 자체의 규칙은 `03-몸-이미지-생성-규칙.md`)
1. **얼굴 포함 상태로 한 장**: 이미지에 눈·코·입·볼 홍조가 이미 그려진 정면/측면 머리와 몸을 넣는다. 얼굴 부품을 따로 뽑지 않는다.
2. 얼굴은 목표 이미지(`01-얼굴-분석.md`)의 규칙을 따름. 후보 체형마다 얼굴 비율(눈 크기·간격)을 약간 바꿔도 되지만 한 후보 안에서는 하나로 고정.
3. 머리카락·옷은 이 후보 이미지에 넣지 않는다(교체 부품은 다른 문서/세션 담당).
4. Tripo 결과에서 눈 모양이 뭉개지는지, 얼굴이 머리 메시에 얼마나 선명히 남는지는 **미확인**. 안 되면 얼굴을 텍스처로 덮는 쪽이 안전하다는 것은 가능성일 뿐 확정 아님.
5. 상업 사용 약관: 메모의 무료 상업 불가(5.2.1)와 지시서의 유료 가능 사이는 사용자가 현재 약관에서 확인(미확인).

## 5. 프롬프트 초안 (얼굴 포함 체형, 한국어 / 영어)
**한국어**: 귀여운 치비 캐릭터의 머리와 몸. 머리가 크다. 큰 둥근 짙은 갈색 눈, 눈 위쪽에 흰 하이라이트 하나, 굵은 윗 속눈썹, 가는 연한 눈썹, 코는 거의 없음, 아주 작은 입으로 약한 미소, 볼에 연한 분홍 홍조. 머리카락 없음, 옷 없음. A자 자세. 정면·옆·뒤, 단색 연회색 배경, 그림자 없음, 부드러운 조명.

# 현재 몸·얼굴 치수 (확인된 것 / 미확인)

기준 몸: 사용자가 Tripo로 만든 남녀 마네킹 `base_model/female/female_base.glb`, `base_model/male/male_base.glb`. 아래 값은 마스터 시트가 Blender에서 정점 좌표를 슬라이스로 잰 것을 옮겼다(나는 이 파일을 직접 열지 않음). 값이 바뀌면 마스터 시트가 기준이다.
표기: **어림** = 마스터 시트가 눈으로 어림한 값, **미확인** = 재지 못함.
좌표: Blender에서 위 +Z, 앞 -Y, 몸 가운데 X=0, 발바닥 Z=0 / GLB 안(Three.js)은 위 +Y, 앞 +Z. 단위 m.

## 2. 얼굴 (마스터 시트 5절)
- 눈, 눈썹, 볼 홍조, 입은 **텍스처에 고정**. 표정 변화 없음(사용자 확정).
- 눈·눈썹·입·홍조의 정확한 위치와 크기는 **미확인**(텍스처 UV 기준 미측정).
- 눈으로 본 특징(어림): 눈이 크고 둥글며 하이라이트가 위쪽, 홍조는 눈 바로 아래 양쪽. 여자는 둥근 눈·얇은 눈썹, 남자는 눈꼬리가 올라간 눈·짙은 눈썹.
- 정수리 두피는 머리카락이 덮을 부분으로 피부색 그대로.
- 목표 이미지와의 비교용으로, 머리 높이(0.61~1.0) 기준 눈 높이 비율을 알면 `01-얼굴-분석.md`의 "눈이 위에서 74%" 값과 비교할 수 있다. 지금은 눈 높이 값이 없어 비교 불가(미확인).

## 3. 이전 모델 기준 (폐기)

## 4. 아직 모르는 것
- 눈, 눈썹, 입, 홍조의 UV 위치와 색값 (마스터 시트 9절)
- 남녀 얼굴 외 형태 차이(손가락, 발가락)
- 게임에서 걷기·낚시를 시켰을 때 몸이 찌그러지는지
- 마스터 시트 수치 자체는 내가 재검증하지 못함. 머리 높이 0.39와 Head 뼈 끝 0.733~0.750이 잘 맞지 않는 점은 시트도 "확인 필요"로 적고 있다.

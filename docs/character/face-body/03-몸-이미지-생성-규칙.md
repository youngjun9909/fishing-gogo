# 기본 몸 이미지 생성 규칙 (이미지 생성 AI용)

목적: 얼굴·머리카락·옷이 **없는** 치비 기본 몸의 정면/측면/뒤 이미지를 만들어 Tripo 등에 넣을 참조로 쓴다.

## 치수
- 기준은 `docs/character/master-sheet.md`(남녀 마네킹)이다: 키 1.000, 머리 높이 약 0.39(키의 약 39%, 약 2.6등신), 머리 폭 0.36~0.40, T자세 팔 벌린 폭 0.72, 가랑이 높이 z 약 0.30~0.32. 값이 바뀌면 시트를 따른다.
- 이 규칙으로 새 후보를 만들 때 머리 비율은 약 39%로 맞춘다(옛 36%와 목표 이미지 약 40%는 폐기/참고). 시트 수치는 내가 재검증하지 못함.

## 이미지 규칙
1. **자세**: T자(팔 수평). 마스터 시트의 기준 몸이 T자세다. 다른 자세는 사용자 확인 필요. 어느 쪽이든 정면·측면·뒤 **세 장이 같은 자세**여야 한다.
2. **다리**: 어깨너비보다 약간 좁게 벌려 서고, 발끝은 정면을 향함. 다리 사이가 보이게(붙지 않게).
3. **손**: 손가락을 펴고 약간 벌림(주먹 금지). 손바닥은 아래.
4. **얼굴**: 체형 후보마다 **얼굴 포함**(눈·코·입·볼 홍조가 그려진 고정 얼굴, 규칙은 `02-눈코입-규칙.md` 2절(표정 변화 없음, 깜빡임 등도 범위 제외)). 눈·입을 별도 부품으로 만들지 않는다. 귀는 사용자가 정할 것(현재 몸은 귀 있음 [메모]).
5. **머리카락 없음**(대머리 형태, 머리 꼭대기가 매끈).
6. **옷 없음**: 몸 전체가 하나의 피부색. 현재 몸처럼 속옷/슈트 느낌도 만들지 않음. 신발 없음(맨발).
7. **배경**: 균일한 단색 연회색(#d0d0d0) 한 가지, 바닥 그림자 없음, 바닥선 없음.
8. **조명**: 정면에서 퍼진 부드러운 빛, 강한 그림자·반사·질감 없음(무광 매끈한 도자기/플라스틱 느낌).
9. **카메라**: 정면·측면·뒤 모두 **정사영에 가까운 같은 높이/거리**, 키가 세 장에서 같은 높이, 몸이 화면 가운데, 위아래 여백 동일.
10. **나란히 배치**: 한 장에 정면·측면·뒤를 가로로 나란히(발 높이 맞춤) 그리거나, 같은 설정으로 세 번 따로 생성. 세 컷의 키·머리 크기가 다르면 3D로 만들 때 어긋남.
11. **금지**: 글자, 눈금자, 원근 과장, 로봇/기계 관절, 짧은 줄 무늬, 성별이 강한 가슴·근육 표현(남녀 공용 몸이라는 결정 [메모]).

## 확인 방법 (사용자)
1. 세 컷에서 머리 꼭대기·턱·발바닥 높이가 같은 가로줄에 오는지 본다.
2. 머리 높이 ÷ 키가 정한 값(약 39%)에 맞는지 그림 편집기 눈금으로 잰다.
3. 손가락·발가락이 흐리거나 5개가 아니면 다시 생성.
4. 통과하면 Tripo에 넣는다. 얼굴은 머리에 포함된 상태로 넣는다(`02-눈코입-규칙.md` 4절 참고).
